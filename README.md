## 🚀 Sobre o Projeto

Repositório dedicado aos exercícios da disciplina de Algoritmos, resolvidos na pseudolinguagem **Portugol Online**.

Este projeto documenta as listas propostas pelo professor Valkennedy Castro e serve como um **Registro de Evolução Pessoal** no aprendizado de lógica de programação.

## 🛠 Tecnologias e Ferramentas

* **Linguagem:** Portugol
* **Interpretador:** Portugol Online (baseado no Portugol Studio) 🇧🇷
* **Sistema Operativo:** Windows 🪟

Todos os algoritmos foram desenvolvidos e testados utilizando a plataforma **Portugol Online**, como parte da grade curricular do curso de Bacharelado em Sistemas de Informação.

<img src="https://icons.iconarchive.com/icons/hopstarter/square-flags/256/Brazil-Flag-icon.png" width="25" style="margin-right: 5px;" /> [Código Fonte do Interpretador Portugol Online](https://github.com/vinyanalista/portugol)

## 💻 Como Utilizar

Cada arquivo `.por` no repositório contém um exercício resolvido.

1. Entre em um interpretador [Portugol Online](https://vinyanalista.github.io/portugol/).
2. Navegue até a pasta da lista desejada.
3. Salve o arquivo `.por`.
4. Abra-o utilizando o interpretador para executar e testar.
